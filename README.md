## Featured Projects

### 1. RentPlace — Rental Marketplace

A rental marketplace for Bangladesh with separate workflows for tenants, landlords, and administrators.

**Tech stack:** Next.js, TypeScript, Tailwind CSS, Express.js, Prisma, PostgreSQL, Stripe

**Key features**
- JWT authentication with access and refresh token handling
- Role-based dashboards and protected routes
- Property listings, search, filters, and pagination
- Rental request management and reviews
- Stripe Checkout payment flow with session verification
- API proxy configuration for frontend and backend deployment

**Architecture:** Next.js frontend and Express REST API maintained in a single repository.

### 2. Blood Care — Donor Coordination Platform

A platform designed to help people connect with blood donors and coordinate blood requests.

**Tech stack:** Next.js, Node.js, MongoDB

**Project goals**
- Make donor discovery easier
- Organize donor and recipient information
- Support blood request coordination
- Build a straightforward interface for urgent requests

**Status:** In development.

### 3. Medical Image Segmentation — Research

Deep learning research focused on segmenting skin lesions in dermoscopic images.

**Tech stack:** Python, PyTorch, computer vision, U-Net-based architectures

**Research focus**
- Medical image preprocessing and segmentation
- Encoder-decoder network architectures
- Attention-based feature fusion and multi-scale learning
- Evaluation using Dice score, IoU, and other segmentation metrics

This research combines practical deep learning implementation with medical image analysis.
