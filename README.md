## About

I'm a full stack developer from Bangladesh. I build web applications with a focus on performance, scalability and maintainable architecture, with most of my work on the backend: REST APIs, database design, authentication and role-based access control.

- Currently building **Blood Care**, a platform connecting blood donors with people in urgent need
- Working deeper with Next.js and scalable backend architecture
- Learning PyTorch and machine learning
- Improving data structures and algorithms through competitive programming
